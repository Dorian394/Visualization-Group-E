# Visualization 2: Regional Analysis

This module provides an **interactive visualization** designed to analyze **regional effects within the dataset**.

## Prerequisites

Before running the notebook, ensure you have the following Python libraries installed:

* `pandas` 
* `altair`

To install the required external dependencies, run the following command in your terminal:

```
pip install pandas altair 
```

## Getting Started

1. Open the [vis-2.ipynb](vis-2.ipynb) notebook in your development environment.
2. Execute the entire notebook (by clicking the *"Run All"* button).
3. The interactive visualization will render at the bottom of the notebook after the data processing is complete (approximately 1 minute).
